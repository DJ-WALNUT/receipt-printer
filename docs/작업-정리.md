# 영수증 프린터 활용 프로그램 작업 정리

2026-11-14 기준. 프로그램을 만들면서 나눈 대화를 정리한 문서다. 사용법은 [README](../README.md)에 있고, 여기에는 무엇을 왜 그렇게 만들었는지와 남은 일을 적는다.

## 한눈에 보기

CPP-3000 감열 영수증 프린터로 열여덟 가지 콘텐츠를 뽑는 파이썬 프로그램을 만들었다. 텍스트 인쇄, 고전게임 열세 가지(스도쿠, 부등호 스도쿠, 노노그램, 지뢰찾기, 미로찾기, 낱말 찾기, 다른 그림 찾기, 오목판, 점과 상자, 틱택토, 빙고, 사다리 타기, 행맨), TRPG 전리품, maimai 레이팅 영수증, 나름로또, 오늘의 타로이며, 모두 `main.py` 허브 하나에서 실행한다.

- **방식**: 글자와 그림을 576도트 폭 흑백 이미지로 그린 뒤 USB 가상 시리얼(COM17)로 ESC/POS 명령을 직접 보낸다. 프린터 드라이버는 쓰지 않는다.
- **종이 절약**: 모든 콘텐츠에 `--preview`가 있어 종이 없이 이미지만 저장할 수 있다. 개발 중 확인은 대부분 미리보기로 했다.
- **진행 중**: 사운드 볼텍스 볼포스 영수증은 데이터 출처를 정하지 못해 아직 만들지 않았다.
- **미뤄 둠**: PC에서 프린터 설정(비프음 크기 등)을 바꾸는 일은 감열지가 넉넉할 때 다시 보기로 했다.

## 프린터와 연결

| 항목 | 내용 |
|---|---|
| 모델 | CPP-3000 (GPRINTER 펌웨어 2.0A, 신화포스 판매) |
| 용지 | 80mm 감열지, 자동 부분 커팅 |
| 해상도 | 203dpi, 가로 576도트 (8도트 = 1mm) |
| 연결 | USB 가상 시리얼 COM17, 38400bps (VID_1CBE, PID_0002) |
| 명령 | ESC/POS |

- **인쇄 순서**: 초기화(`ESC @`) → 이미지를 64줄씩 래스터로 전송(`GS v 0`) → 4줄 이송(`ESC d 4`) → 부분 커팅(`GS V B 0`).
- **상태 확인**: `DLE EOT n`으로 묻고 `0x16`이 오면 정상이다.
- **내장 한글**: CP949로 보내면 내장 폰트로도 한글이 찍힌다. 지금은 쓰지 않고 전부 이미지로 인쇄한다.
- **감열지 특성**: 점이 번져서 미리보기보다 진하게 나온다. 반전 글자(검은 바탕에 흰 글자)는 굵은 글꼴이어야 읽힌다.

### 텍스트 인쇄

- 갈무리 폰트를 원래 픽셀 크기로 그린 뒤 정수 배로 확대한다. 그래야 도트가 뭉개지지 않는다.
- 인쇄 샘플을 보고 고른 스타일은 제목, 소제목, 본문, 굵게, 작게, 반전, 큰 반전이다.
- `@36 텍스트`처럼 글자 높이를 도트로 지정할 수 있다. 가능한 높이는 16, 20, 24, 30, 36, 40, 45, 48, 60이고, 굵게는 24, 36, 48만 된다.
- 굵은 글꼴에 없는 일본어 글자는 글자 단위로 다른 글꼴(Galmuri11, MS Gothic)로 대체한다.

### 스도쿠

- 난이도는 쉬움, 보통, 어려움이고 채워진 칸은 각각 40, 32, 26개다.
- 영수증에 `SM482913` 같은 시드번호가 찍히고, `--answer SM482913`으로 정답을 뽑는다.

### 미로찾기

- 스도쿠와 같은 틀이다. 난이도는 쉬움(12×12칸), 보통(16×22칸), 어려움(20×32칸)이고, 영수증이 세로로 길다는 점을 살려 어려울수록 세로로 길어진다.
- 되돌아가기 방식으로 만들어 고리가 없으므로 길은 항상 하나뿐이다. 왼쪽 위가 출발, 오른쪽 아래가 도착이다.
- 통로 폭은 펜으로 그을 수 있게 3.5mm 이상으로 잡았다.
- `--answer M482913`으로 정답 길을 굵은 선으로 그린 정답지를 뽑는다.

### 전리품 뽑기

- 등급 확률은 일반 60%, 고급 25%, 희귀 10%, 영웅 4%, 전설 1%다.
- `--loop`로 Enter를 누를 때마다 한 장씩 나오는 자판기 모드가 된다.
- 번호(`--seed`)가 같으면 같은 아이템이 나온다.

### maimai 레이팅 영수증

- 아이디를 넣으면 maishift 프로필 페이지를 한 번 요청해서 읽는다.
- 페이지에 들어 있는 직렬화 데이터를 코드 실행 없이 직접 해석하는 파서를 만들었다.
- 아이디가 없거나 비공개면 오류 메시지만 내고 인쇄하지 않는다. 종이 낭비를 막기 위한 요청 사항이었다.
- maishift의 robots.txt는 프로필 페이지를 허용하고 요청 간격 5초를 요구한다. 한 번 실행에 요청은 한 번이다.

### 나름로또

- 숫자 범위, 뽑는 개수, 게임 수, 상품 글자는 파일 맨 위 설정에서 바꾼다(`NUMBER_MIN`, `NUMBER_MAX`, `PICKS`, `GAMES`, `PRIZE_TEXT`).
- 센터 정보는 광명시청소년재단 누리집에서 가져왔다. 주소, 미션 문구, 공간 이름 여섯 곳이 들어간다.
- 회차는 개관일(2013-02-01)부터 센 주 수다.
- 결제 금액과 결제 수단 대신 상품 칸을 넣었다. 비워 두면 손으로 적을 밑줄이 찍힌다.
- "체험용 복권입니다. 실제 복권이 아닙니다." 문구가 함께 찍힌다.

### 오늘의 타로

- 카드 22장은 71×95 도트로 직접 그렸다. Balatro의 그림을 베끼지 않고 전통 타로 도상을 단순하게 그렸다.
- 역방향(30%)이면 카드 그림이 거꾸로 찍힌다.
- 카드 효과는 Balatro의 타로 효과에서 출발했지만, 게임 용어를 빼고 일상 이야기로 다시 썼다.
- 운명의 수레바퀴는 실제로 1/4 확률을 굴려 "반짝! 오늘이 그날입니다" 또는 "꽝! 평소대로 가세요"를 찍는다.
- 영수증 아래의 족보, 점수, 행운의 무늬 칸은 아직 게임 느낌 그대로다.

## 구조와 공용 규칙

```
main.py              허브 (메뉴에서 콘텐츠 골라 실행)
receipt.py           공용 모듈 (글자 그리기, 이미지 저장, 프린터 전송)
text/                텍스트 인쇄
games/               고전게임 13종 (sudoku/ futoshiki/ nonogram/ minesweeper/ maze/ wordsearch/ spot/
                     omok/ dots/ tictactoe/ bingo/ ladder/ hangman/)
fortune/             오늘의 운세 3종 (loot/ lotto/ tarot/)
maimai/              maimai 레이팅 영수증
  <콘텐츠 폴더>/<스크립트>.py
  <콘텐츠 폴더>/output/   그 콘텐츠가 만든 이미지
Galmuri-v2.40.4/     폰트
docs/                이 문서
```

- **메뉴와 같은 폴더 구조**: 고전게임은 `games/`, 오늘의 운세는 `fortune/` 아래에 둔다. 처음에는 전부 맨 위에 있었는데 콘텐츠가 18개로 늘어 묶었다.
- **콘텐츠마다 폴더 하나**: 스크립트와 그 스크립트가 만든 이미지가 같은 폴더에 들어간다.
- **전부 저장**: 인쇄하든 미리보기만 하든 이미지는 `<콘텐츠 폴더>/output/YYYYMMDD_HHMMSS_태그.png`로 저장되고 덮어쓰지 않는다.
- **공통 옵션**: `--port`(기본 COM17), `--preview`(저장만), `--no-cut`(커팅 안 함).
- **허브**: `python main.py`는 메뉴, `python main.py <이름> <옵션…>`은 해당 스크립트로 옵션을 그대로 넘긴다. 콘텐츠를 추가할 때는 `CONTENTS`에 한 줄을 넣고 `MENU`에도 이름을 넣는다.
- **메뉴 묶음**: 스도쿠·미로찾기·낱말 찾기·오목판은 "고전게임", 전리품 뽑기·나름로또·오늘의 타로는 "오늘의 운세"로 묶었다. 콘텐츠를 고르면 몇 장 뽑을지 묻고(최대 20장), 장마다 새 판을 만든다.
- **git 제외**: `.venv/`, `__pycache__/`, `output/`.

## 주요 결정과 이유

| 결정 | 이유 |
|---|---|
| 글자를 이미지로 그려서 인쇄 | 갈무리 폰트를 쓰고 싶었고, 프린터 내장 폰트는 바꿔 넣을 수 없다 |
| 확인은 미리보기 이미지로 | 감열지가 아깝다는 요청 |
| 프린터 설정 명령을 추측해서 보내지 않음 | 설정표에 통신 속도와 USB 모드가 있어, 값이 틀리면 COM17 연결이 끊길 수 있다 |
| 드라이버 설치 파일을 실행하지 않음 | 출처를 확인할 수 없는 실행 파일이다 |
| 출력 위치를 `컨텐츠/output/`으로 | 처음에는 `output/컨텐츠/`로 만들었다가 요청에 따라 바꿨다 |
| maimai 기본 곡 수를 5곡에서 3곡으로 | 5곡씩이면 영수증이 24cm였다 |
| 로또에서 금액과 결제 수단을 빼고 상품 칸으로 | 요청 사항 |
| 타로 효과 문구를 일상 이야기로 | 칩, 배수 같은 게임 용어가 너무 게임 같다는 의견 |
| Vaddict를 자동으로 읽지 않음 | 아래 "사운드 볼텍스 볼포스 영수증" 참고 |

## 시행착오

| 문제 | 해결 |
|---|---|
| 두 번째 인쇄에서 시리얼 포트 열기 실패(오류 31) | 일시적인 현상이라 `send()`에 3회 재시도를 넣었다 |
| 반전 글자가 뭉개져 읽기 어려움 | 반전 스타일은 굵은 글꼴만 쓰도록 했다 |
| 굵은 글꼴에 일본어 글자가 없음 | 글자 단위로 다른 글꼴로 대체 |
| PowerShell에서 `python -c`의 따옴표가 깨지고 한글 출력이 깨짐 | 시험 코드를 파일로 만들고 `PYTHONUTF8=1`로 실행 |
| 전리품 `--loop`가 입력이 끝나면 오류로 종료 | 입력 종료를 정상 종료로 처리 |
| 도끼 아이콘이 곡괭이처럼 보임 | 다시 그렸다 |
| 타로 카드 네 장(바보, 매달린 사람, 탑, 심판)이 지저분함 | 다시 그리고 전체 카드를 한 장에 모아 확인 |
| 나름청소년활동센터 정보를 검색으로 못 찾음 | 알려 준 누리집 주소에서 직접 읽었다 |
| Vaddict의 robots.txt를 읽기 전에 프로필 페이지를 두 번 요청함 | 순서를 잘못 잡았다. 이후 추가 요청은 하지 않았다 |

## 사운드 볼텍스 볼포스 영수증 (미정)

아이디로 최신 볼포스 데이터를 읽어 영수증을 만들고 싶다는 요청이다. 아직 만들지 않았다.

- **`pa` 문제는 풀린다**: Vaddict 주소의 `pa`(참조 데이터 번호)를 빼고 요청해도 페이지가 오고, 드롭다운의 첫 항목이 항상 최신이다.
- **자동 접근은 금지되어 있다**: robots.txt가 첫 화면 외에는 전부 막고 있다. [2차 이용 공지](https://vaddict.b35.jp/news/2023/022600.php)에도 HTML 스크래핑을 인정하지 않는다고 적혀 있다.
- **정식 경로가 있다**: 같은 공지에 따르면 용도를 알려 주면 전용 API를 만들어 준다. 기본 무상이고 크레딧 표기가 조건이며, 문의하면 48시간 안에 답장을 준다고 한다.

선택지는 세 가지다.

1. Vaddict 운영자에게 API를 요청한다.
2. 브라우저에서 저장한 페이지 파일을 스크립트가 읽게 한다. 사이트에 자동으로 접속하지 않는다.
3. 다른 출처를 쓴다. Kamaitachi는 공개 API가 있지만 가입한 사람만 조회된다. 공식 e-amusement 스코어 CSV는 본인 것만 받을 수 있다. 두 가지 모두 기억에 의존한 내용이라 현재 규칙은 확인이 필요하다.
