# 숨은 글자 찾기 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 같은 글자가 가득한 판에서 섞인 비슷한 글자를 찾는 퍼즐 콘텐츠 `games/oddchar/` 를 만든다.

**Architecture:** 다른 퍼즐(spot, wordsearch)과 같은 단일 스크립트 + `content.toml`. 시드번호에서 판 전체가 결정되고, `--answer` 로 같은 판의 정답지를 그린다. 그리기는 `receipt.py` 의 `draw_run`/`size_style`/`render`/`stack`/`output` 을 쓴다.

**Tech Stack:** Python 3, Pillow, pytest. 키오스크는 `content.toml` 만으로 메뉴에 뜬다.

**Spec:** `docs/superpowers/specs/2026-11-17-oddchar-design.md`

## Global Constraints

- 시드 글자 `G`, 형식 `G` + 난이도(E/M/H) + 찾을 개수(1~3) + 여섯 자리 숫자 (예: `GM1482913`). 소문자도 받는다.
- 메뉴: 고전게임 묶음, `order = 75` (다른 그림 찾기 70 다음).
- 키오스크 모드: `new`(난이도 choice, 개수 number 1~3 기본 1, `same_sheets = true`), `answer`(`sheets = false`, pattern `[Gg][EMHemh][1-3]\d{6}`).
- 이미지 저장 위치 `games/oddchar/output/` (receipt.output 이 처리).

## Review Focus

- 감열 픽셀 글꼴에서 두 글자가 똑같이 그려지는 짝 (예: 0/O) → 풀 수 없는 판. 짝마다 그 난이도 크기에서 그림이 다른지 테스트로 확인.
- 다른 글자 여러 개가 붙어 있어 하나로 보이는 경우 → 서로 가로·세로·대각선으로 이웃하지 않게.
- 잘못된 시드번호(난이도 X, 개수 0/4, 숫자 아님, 다른 콘텐츠 글자) → argparse 오류로 끝난다.
- 같은 시드번호 → 언제나 같은 짝·같은 위치 (정답지가 문제와 일치).
- 판이 종이 폭(576px)을 넘지 않는다.
