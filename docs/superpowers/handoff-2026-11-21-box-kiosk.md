## 무엇을 만드나 (한 문단)

라즈베리파이 3B+에 공식 7인치 터치스크린(800×480)을 붙여 프린터·파이·화면을 한 상자로 만드는 **두 번째 설치 방식**. 아이패드 방식은 그대로 두고 나란히 고르는 선택지다. 같은 페이지를 `?box=1`로 열면 상자 모드가 되어 (1) 고르는 화면 → 설정 화면 두 장 넘기기, (2) 화면 안 키보드(숫자 키패드·영문·두벌식 한글)로 바뀐다. 설치 스크립트가 `--box`이면 `cage` + Chromium으로 부팅 때 화면을 띄운다. OS는 Raspberry Pi OS Lite 64비트 (Bookworm/Trixie 미확인 → 스크립트가 둘 다 처리).

## 대화에서 정한 것 (바꾸지 말 것)

- 목적: "단일 키오스크 모델". 와이파이가 없는 곳 포함 아무 데서나 켜서 쓴다. 아이패드를 대체하지 않는다.
- 화면 배치: 시안 A "두 장 넘기기" (시안 B 좌우 나누기, C 덮는 패널은 버림).
- 키보드: 시안 그대로 세 가지. 한글은 두벌식 (천지인 아님). 관리자 한글 입력도 상자 화면에서 한다 (핫스팟 방식은 버림).
- 코드 구조: 같은 페이지 + `?box=1` (상자 전용 페이지, 화면 크기 자동 전환은 버림).
- OS: Pi OS Lite + `cage` + Chromium (Desktop 버림).
- 상자에서는 '관리 페이지'(`/admin`) 버튼을 숨긴다. 관리 페이지는 휴대폰/PC에서.
- 60초 자동 복귀 등 작성자 판단 8가지도 사용자가 승인했다 (설계 문서의 "작성자 판단" 표시).

시안 그림은 `.superpowers/brainstorm/`(git 무시)에만 있다. 필요한 내용은 설계 문서의 ASCII 그림과 키보드 표에 다 옮겨 두었으니 시안 파일 없이 진행해도 된다.

## 알아 두면 좋은 것

- **테스트**: `.venv\Scripts\python -m pytest -q -m "not slow"`. JS 테스트는 `node --test tests/js/` (개발 PC Node 24.16). Task 1에서 `tests/test_js.py`를 만들면 pytest가 JS 테스트도 돌린다.
- **PC에서 띄우기**: `$env:KIOSK_PREVIEW="1"; $env:KIOSK_PIN="1234"; .venv\Scripts\python -m kiosk` → `http://localhost:8080/?box=1`, 개발자 도구 기기 모드 800×480.
- **브라우저 코드 규칙**: ES2017까지, CSS에서 `clamp()`, `:has()`, flex `gap`, `inset`, `aspect-ratio` 금지 (오래된 아이패드).
- **콘텐츠는 손대지 않는다**: `content.toml`·콘텐츠 스크립트는 `receipt-contents` 브랜치에서 만든다 ([콘텐츠-머지-안내.md](../콘텐츠-머지-안내.md)). maimai 오류 문구도 그대로 둔다.
- **이미 있는 것**: 관리자 PIN 덮개는 이미 화면 숫자 버튼(`app.js` `openPin`), 60초/3분 자동 복귀도 이미 있다(`IDLE_VISITOR`, `IDLE_STAFF`). 방문자에게 사다리 `names`는 서버가 닉네임 고르기(`pick`)로 바꿔 내려줘서 방문자는 한글 키보드를 안 본다.
- **서버 변경은 하나뿐**: `hub.py` `_describe_field`가 `pattern`을 내려주게 한다 (Task 4, 키보드 종류를 고르는 데 필요).
