# 숨은 글자 찾기 설계

## 의도

같은 글자가 가득한 판에서 딱 하나(또는 몇 개) 섞인 비슷한 글자를 찾는 퍼즐 (예: 6 사이의 8).
'윌리를 찾아라' 같은 찾기 놀이를 영수증 한 장으로. 이름은 남의 작품 이름을 쓰지 않고 "숨은 글자 찾기".

## 목표 / 하지 않을 것

- 목표: 기존 퍼즐(다른 그림 찾기 등)과 같은 구조. 시드번호로 같은 판과 정답을 다시 만든다. 키오스크 설정 파일 하나로 메뉴에 뜬다.
- 하지 않음: 그림·캐릭터 숨기기, 화면에서 정답 판정.

## 접근

- 고른 것: 헷갈리는 글자 짝 목록 + 판마다 무작위 짝 하나. 난이도는 판 크기·글자 크기·짝의 닮음 정도로.
- 버린 것: 판 하나에 여러 짝을 섞기 (찾을 대상이 흐려진다), 글꼴을 바꿔 숨기기 (감열 인쇄에서 구분이 안 된다).

## 정한 것

- 콘텐츠 폴더 `games/oddchar/`, 시드 글자 `G`, 메뉴는 고전게임 묶음에서 다른 그림 찾기 다음 (order 75).
- 시드번호: `G` + 난이도(E/M/H) + 찾을 개수(1~3) + 여섯 자리 숫자. 예: `GM1482913`.
- 난이도: 쉬움 16x22 (글자 3mm), 보통 22x30 (2.5mm), 어려움 28x40 (2mm). 짝은 그 난이도 글자 크기에서 6점 이하로 다른 것만 자동으로 고른다 (2026-11-17 조정: 크기마다 글꼴이 달라 닮은 정도가 달라진다).
- 찾을 개수 1~3 (기본 1). 다른 글자끼리는 붙어 있지 않게 떨어뜨린다.
- 정답지: 같은 판에서 숨은 글자에 동그라미, 나머지 글자는 흐리게(점).
- 키오스크: 새 판(난이도, 개수, 여러 장·같은 문제), 정답 인쇄(시드번호).

## 빌더에게 맡긴 것

- 글자 짝 목록의 구체 내용 (아주 닮은 18쌍: 한글 음절 12, 영문 5, 숫자 1).
- 글자 크기, 줄 수 등 세부 배치.
