# 같은 문제 여러 장 뽑기

## 왜

여러 명이 같은 문제를 받아 누가 먼저 푸는지 겨루는 활동(타임어택)을 하려면 같은 문제가 여러 장 필요하다. 지금은 여러 장을 뽑으면 장마다 스크립트를 새로 실행해서 매번 다른 문제가 나온다.

## 목표

- 터미널 메뉴와 키오스크에서 "같은 문제로 N장"을 고를 수 있다.
- 대상: 스도쿠, 부등호 스도쿠, 노노그램, 지뢰찾기 퍼즐, 미로찾기, 낱말 찾기(새 판, 낱말 직접 넣기), 다른 그림 찾기.
- 기본 동작은 지금과 같다 (장마다 다른 문제).
- 모든 장에 같은 시드번호가 찍혀, 정답 인쇄를 지금 그대로 쓴다.

## 하지 않는 것

- 시드번호로 예전 문제를 다시 뽑는 기능.
- 장 수 제한 변경 (방문자 4장, 관리자 20장 그대로).

## 방식

고른 방식: **공통 인쇄 함수에 `--copies N`을 넣는다.** 스크립트는 문제를 한 번 만들고, `receipt.output()`이 같은 이미지를 N번 인쇄한다. 콘텐츠 스크립트는 고치지 않는다. 문제를 한 번만 만들므로 파이에서도 빠르다.

버린 방식: 스크립트마다 "시드번호로 문제 다시 뽑기" 옵션을 넣고 장마다 실행. 재인쇄가 가능해지지만 스크립트 일곱 개를 모두 고쳐야 하고, 장마다 문제를 다시 만들어 느리다.

## 설계

- **`receipt.py`**: `add_output_args`에 `--copies`(1~20, 기본 1). `output()`은 이미지를 한 번 저장하고 `copies`번 전송한다. 미리보기에서는 저장만 하고 장 수를 결과 문장에 적는다.
- **`hub.py`**: 모드 키 `same_sheets`(기본 `false`). `sheets = false`인 모드에 켜면 설정 오류. `describe()`가 화면에 내려준다. `check_same(mode, same)`이 요청을 검사한다.
- **`content.toml`**: 대상 모드 여덟 개에 `same_sheets = true`.
- **`main.py`**: `same_sheets`인 모드에서 2장 이상을 고르면 "같은 문제로 뽑을까요? (y/N)"를 묻는다. 예이면 스크립트를 한 번만 `--copies N`으로 실행한다. 직접 실행: `python main.py sudoku --copies 4`.
- **키오스크** (`kiosk` 브랜치):
  - 화면: `same_sheets`인 모드는 "몇 장?" 아래에 `장마다 다르게 / 모두 같게` 선택이 나온다. 기본은 다르게.
  - 서버: `/api/print`가 `same`을 받아 `hub.check_same`으로 검사한다. 1장이면 무시한다.
  - 대기열: 같은 문제 작업은 스크립트를 한 번만 `--copies N`으로 실행하고, 제한 시간을 장 수만큼 늘린다.

## 감수하는 점

같은 문제 작업은 한 번의 실행으로 전부 인쇄한다. 그래서 키오스크의 진행 표시가 장마다 올라가지 않고 끝날 때 한꺼번에 완료되며, 관리자의 취소는 인쇄 도중에는 먹지 않는다. 화면에는 "같은 문제 N장을 뽑는 중"으로 보여준다.
